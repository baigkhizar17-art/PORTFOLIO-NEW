CASE 01
ICD-10-CM diagnosis coding workflow

Objective

Demonstrate how to move from a fictional outpatient note to a defensible diagnosis code selection.

Simulated documentation

Fictional adult outpatient visit. Provider documents a diagnosis and plan in the assessment. No real identifiers or clinical records are used.

Review steps

  1. Identify the provider-documented diagnosis and encounter context.
  2. Check the Alphabetic Index, then confirm in the Tabular List.
  3. Review inclusion notes, exclusions, laterality, specificity, and required additional codes.
  4. Confirm code year and sequencing instructions.

Code assignment

To be completed: enter the verified ICD-10-CM code and short rationale after checking the current official code set.

Quality check

Do not code symptoms separately when they are integral to a confirmed diagnosis unless guidelines or documentation require it.

CASE 02
Radiology report coding review

Objective

Show a structured approach to a fictional radiology report and distinguish documented findings from assumptions.

Simulated documentation

Fictional imaging report containing an indication, modality, findings, impression, and documented procedure details.

Review steps

  1. Read the indication and final impression; identify what the provider actually states.
  2. Separate diagnosis coding considerations from procedure/service coding considerations.
  3. Confirm modality, body region, contrast details, and service elements where relevant.
  4. Check code descriptors and applicable bundling or reporting rules using current references.

Code assignment

To be completed: document verified diagnosis and procedure/service codes with the reference used.

Quality check

Do not infer a definitive diagnosis from an uncertain finding or code a procedure that is not documented.

CASE 03
CPT procedure and service coding

Objective

Demonstrate code selection from the documented service—not from a guessed procedure name.

Simulated documentation

A fictional provider note describing a procedure, its site, and relevant service details.

Review steps

  1. Identify the exact documented service and any distinct components.
  2. Search the CPT index and confirm the descriptor in the codebook.
  3. Review parenthetical instructions, modifiers, and applicable bundling edits.
  4. Confirm payer and setting requirements separately when relevant.

Code assignment

To be completed: add the verified CPT code, descriptor, and explanation of documentation support.

Quality check

Never select a code solely because it sounds similar to the procedure described.

CASE 04
Clinical documentation review & query awareness

Objective

Recognize documentation that may not support a specific code assignment.

Simulated issue

A fictional note contains conflicting descriptions of a condition, or lacks a detail needed to select the most specific code.

Review steps

  1. Identify the exact inconsistency or missing element.
  2. Review the full record for clarification already documented.
  3. Do not resolve clinical ambiguity by guessing.
  4. Escalate through the organization’s approved query or clarification process when appropriate.

Learning outcome

Support compliant coding by distinguishing documented facts from assumptions and following the approved escalation process.

CASE 05
Coding quality review checklist

Objective

Apply a repeatable quality check to a fictional coding worksheet.

Review checklist

  • Does the code match the provider documentation?
  • Is the code at the supported level of specificity?
  • Were index and tabular instructions reviewed?
  • Are sequencing and additional-code requirements addressed?
  • Are unsupported symptoms, diagnoses, or procedures avoided?
  • Are the applicable code year and reference recorded?

Demonstration artifact

Create a synthetic Excel tracker with columns for case ID, code submitted, review finding, guideline/reference, correction, and reviewer note. Do not use real patient identifiers or internship records.
