# Mirza Khizar Baig | Medical Coding Portfolio

A responsive, single-page portfolio website for **Mirza Khizar Baig**, a B.Pharm graduate with medical coding internship exposure in ICD-10-CM, CPT, HCPCS and radiology report coding.

The site presents my profile, skills, simulated coding case studies, experience, education and certifications in one clean, recruiter-friendly page.

## Sections

- **Home**: Introduction, profile card and resume download
- **About**: Approach to coding (documentation first, detail-oriented review, privacy-conscious)
- **Skills**: ICD-10-CM, CPT, HCPCS, radiology report coding, chart abstraction, clinical documentation review, medical terminology, anatomy and physiology, HIPAA confidentiality, MS Excel and Word
- **Case Studies**: Five simulated, expandable workflows
  1. ICD-10-CM diagnosis coding workflow
  2. Radiology report coding review
  3. CPT procedure and service coding
  4. Clinical documentation review and query awareness
  5. Coding quality review checklist
- **Experience and Education**: Medical Coder Intern (6 months), B.Pharm (CGPA 7.22/10), pharmacy shop experience, certifications
- **Contact**: Email and LinkedIn links

## Important Note on Case Studies

All case studies are **fictional, educational demonstrations**. They do not contain real patient records, employer data or audited coding results. Code fields are intentionally marked "to be completed / verify with current code set" so no unvalidated code is shown as a final assignment.

## Tech Stack

- HTML5
- CSS3 (custom properties, CSS Grid, Flexbox, responsive media queries)
- No frameworks, no JavaScript dependencies, no build step

## Features

- Fully responsive (desktop, tablet, mobile)
- Sticky navigation with smooth scrolling
- Accordion-style case studies using native `<details>` / `<summary>`
- Downloadable resume button
- Lightweight, single-file design that loads fast

## Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Open the folder and double-click `index.html` in any browser.
3. Place your resume PDF in the same folder as `Mirza_Khizar_Baig_Resume.pdf` so the download button works.

## Deploy with GitHub Pages

1. Push the files to your repository.
2. Go to **Settings > Pages**.
3. Under **Source**, select the `main` branch and `/ (root)` folder, then save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
